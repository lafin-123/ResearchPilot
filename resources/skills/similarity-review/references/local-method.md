# 本地文本对照方法与限制

## 实际计算

ResearchPilot 的纯函数 `compareTexts(draft, sources)` 只处理调用方显式传入的字符串。先按 Unicode NFKC 归一化、忽略大小写与标点；中日韩字符按单字计，其余按字母/数字词项计。比较连续 8 个词项的精确窗口，计算独特重合窗口数，并选择代表性片段对齐。

- 原文最多前 40,000 个 UTF-16 字符。
- 最多 6 个来源，每个最多前 40,000 字符。
- 来源标签最多 120 字符；ID 最多 80 字符。
- 每个来源最多展示 8 处原文中不重叠的匹配，摘录最多 180 字符。
- 返回位置是从 0 开始、右端不包含的 UTF-16 偏移；界面显示为从 1 开始的字符范围。
- 来源多次出现同一窗口时，采用首次位置作为代表，不是穷尽对齐。
- 报告返回来源位置但不返回来源正文；原文摘录仍可能含敏感信息。

## 不计算什么

不做语义检索、跨语言对齐、风格归因、数据库查询或平台评分。标点归一化可能使不同写法匹配；词序改变、同义转述或短于窗口的复制可能漏掉。段落长短、中英文分词方式和重复窗口去重使“窗口数”不能换算为通用相似百分比。

## 人工判读表

| 线索 | 进一步检查 | 行动 |
|---|---|---|
| 连续精确重合 | 是否直接引语，有无恰当归属 | 保留必要引语/引号与来源，或规范转述 |
| 方法术语重合 | 是否必须保持标准名称 | 保留准确术语，不强制改词 |
| 自身旧文重合 | 既往发表状态、引用与披露 | 核对出版物政策并明确归属 |
| 零窗口重合 | 是否只是未覆盖、短句或语义复制 | 不发原创结论，人工审阅主张来源 |
| 用户报告标红 | 平台覆盖、排除规则与实际来源是否可见 | 只记录用户提供的信息，不推断数据库结果 |

任何真实外部检测都需要独立的授权、合同与隐私评估；此功能没有这样的连接，也不应把论文提交给未知站点。
