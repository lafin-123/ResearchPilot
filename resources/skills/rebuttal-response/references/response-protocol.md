# 回应路径与事实核对

## 每项回应的四部分

1. 原始关切：保留审稿人原话，准确理解其针对的主张或方法。
2. 直接答复：同意、部分同意或有依据的不同意。避免只说“感谢建议”。
3. 实际动作与证据：已经修改/分析/实验了什么，结果支持到什么程度。
4. 稿件位置与剩余限制：版本、章节、表/图、真实页码行号。没有稳定分页则用章节和原句定位。

## 按状态写

| 状态 | 应如何表述 | 所需依据 |
|---|---|---|
| 已完成 | 写明具体动作及发现，引用修订位置 | 修订稿或实际运行产物 |
| 部分完成 | 明确完成的子项与未完成原因 | 已有证据 + 剩余问题 |
| 计划中 | 写作计划，不伪装成已经验证 | 可执行方案与时间/资源条件 |
| 不同意 | 回答底层关切，解释范围和依据 | 真实证据，必要时增加限制说明 |
| 待核验 | 明确缺少材料，不做完成声明 | 请求缺失稿件、结果或记录 |

## 常见失真

- 回复写“我们进行了五次独立实验”，产物只有五个随机种子但没有独立采样：不能暗示独立生物重复。
- 新增实验失败：透明报告并调整论断，不隐藏失败或制造显著性。
- 审稿人要求一个超出范围的研究：解释范围与现有证据，必要时加入未来工作，不承诺已解决。
- 修改文稿后分页变化：重新核对定位，不能沿用旧页码。
- 同一问题出现在多条评论：逐条短答并指向同一真实改动，不留空或仅说“见上”。

## 最后核对

逐项检查主张、数字、图表、文献、工作状态和定位。把回复与实际修订做双向映射：每个“已改”能找到稿件变化；每个重要稿件变化在回复或总说明中透明交代。给作者留出确认意见和签署的步骤，不以自动输出替代作者责任。
