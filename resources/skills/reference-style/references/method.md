# 参考文献格式的方法检查

## 本领域检查

- 以用户提供或实际访问的作者指南为依据，记录URL、可见版本和获取日期，不凭期刊名称推测当前规则。
- 逐条将强制要求、建议和未知映射到实际稿件位置，区分格式修改与科学内容修改。
- 作者贡献、伦理、利益冲突、独家投稿与签名必须由作者确认；不登录账户或自动投稿，不保证录用。

## 应拒绝的捷径

缺字段不能编页码卷期DOI。没有真实条目与目标样式时，不生成声称已完成的格式统一和缺失字段表；可以交缺口表、草案或方法计划。实际计算、搜索、访问和修改各自记录真实状态。

## 交付验收

结果能否由独立读者从所列输入和定位追溯？是否把来源事实、方法假设和作者解释分开？未知与不适用是否各有理由？任何失败都应保留，不通过改写状态隐藏。
