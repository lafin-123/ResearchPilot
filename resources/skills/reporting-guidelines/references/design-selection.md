# 从研究设计选择报告指南

以下仅是指南族的初步定位，不是官方清单副本，也不宣称为最新版本。使用前以研究设计、具体学科扩展和目标出版物要求为准。若没有查阅实际版本，不生成貌似官方的条目编号。

| 研究设计 | 可考虑的指南族 | 先确认 |
|---|---|---|
| 随机干预试验 | CONSORT；方案可考虑 SPIRIT | 分配单位、随机过程、注册、主要终点与分析人群 |
| 观察性队列、病例对照、横断面 | STROBE | 抽样方式、时间关系、混杂与选择偏倚 |
| 系统综述 / 证据综合 | PRISMA 及适用扩展 | 检索、纳入排除、方案、筛选与综合类型 |
| 诊断准确性 | STARD | 参考标准、阈值、受试者流程、盲法 |
| 预测模型 | TRIPOD 及适用扩展 | 开发或验证、数据划分、校准、模型可用性 |
| 动物研究 | ARRIVE | 实验单位、福利、随机化、盲法、样本量依据 |
| 质性研究 | SRQR 或 COREQ（视方法） | 理论框架、取样、研究者角色、分析与可信度 |
| 计算方法、机器学习基准 | 目标会议/期刊清单及领域规范 | 数据来源许可、划分泄漏、算力、seed、基线公平性、失败和复现 |

不能用一个通用表替代所有指南。混合方法可能需要多个清单，须说明各自适用范围。对于学位论文和非临床实验，先核对实际提交要求。

## 证据化状态

- 有定位：找到实际文本且信息充分，记录章节/页码/表格；仍不表示事实已独立验证。
- 部分：有相关表述但缺少关键细节，明确缺的是什么。
- 缺失：实际审阅范围内未找到；不要写成“作者没有做过”。
- 不适用：说明研究设计为什么不适用，不得用作回避缺口。
- 待确认：设计、指南版本或证据不足，保持未解决。

## 易错的“补写”

不能替研究补做过去的预注册，不能写不存在的伦理批准，不能把随机种子当作随机分组，不能把重复训练次数当独立样本量，不能把未统计的失败称为零。若作者无法追溯，报告无法追溯及其影响，而不是猜一个合理值。
