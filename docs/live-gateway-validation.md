## 修复的实际问题

- 之前 provider.test 只读取模型列表，现在和模型发现分离，必须收到真实推理文本才报成功。
- 修复主进程与 Agent 子进程网络代理不一致。
- 原 Windows PowerShell 工具返回 `0xC0000142`，实验没有启动。没有关闭 sandbox 或伪装成功；新增受项目范围、参数校验、源哈希复核和逐次审批保护的原生 MCP 动作，调用现有应用实验服务。
- 实验日志／manifest 写入辅助方法原先没有被调用，现接入完成路径。
- 开发调试端口原先固定 9222，造成隔离测试实例冲突；现尊重测试工具传入的端口，否则使用动态端口。
- GET 模型列表在瞬时连接重置时最多重试一次；不自动重试付费推理 POST，不静默替换模型。
