# ResearchPilot 0.7：研究笔记与页面关联

本轮参考 Notion 的页面、收藏和反向链接交互，将它们限定为本地科研笔记。保持中性色、免登录和现有文献/实验流程。

## 功能范围

- 每项目独立的研究笔记，标题与 Markdown 正文保存于本地 SQLite。
- 空白、研究问题、阅读摘记和实验记录模板。模板只提供结构，不预填虚构发现。
- 笔记标题/正文检索、收藏列表、回收站与恢复。
- 编辑/预览，显式保存与 Ctrl+S。切换笔记或页面时内存草稿保留；关闭或刷新前需保存。
- 使用稳定笔记 ID 的页面链接；修改目标标题不会改变目标 ID。
- 反向链接根据已保存正文中的有效内部链接生成，不把同名文本当作链接。
- 保存使用整数 revision 检查，旧草稿与新版本冲突时拒绝覆盖。
- Markdown 导出由用户点击触发。预览不执行原始 HTML，不自动加载外部图片。

## 使用方式

从侧栏“研究笔记”进入，选择模板创建笔记。填写标题和正文后保存；用“插入页面链接”选择当前项目的另一篇笔记。目标笔记的反向链接区域可看到引用来源。误删笔记进入回收站，不立即永久销毁。

首页显示收藏与最近笔记，也保留最近文稿和研究任务入口。

## 边界

这不是完整 Notion 块编辑器，没有多人协作、云同步、嵌套数据库视图、拖拽块或无限历史版本。revision 是冲突控制，不是历史版本浏览。

独立研究笔记当前不自动加入文献 BM25/RAG，也不自动交给模型。已有“文献资料”中的标题、摘要和阅读笔记仍按既有规则索引；两种笔记在界面上明确区分。

当前工作区是本地单用户。数据保存在数据库，不能把笔记列表误当成项目目录里已自动生成的 Markdown 文件；需要文件时使用导出。
