# ResearchPilot 0.8：成果管理与 AI 阅读摘记

## 交互方向

- **文献库**：标题优先的紧凑列表，右侧阅读摘要、来源、AI 草稿和人工笔记；导入入口收拢为“添加文献”。
- **实验台**：默认查看运行结果、真实指标、历史、日志和文件；代码与环境配置放在高级标签，已有未保存草稿仍受保护。
- **图表与演示**：默认预览、来源核对、SVG 与可编辑 PPT 导出；流程自动创建成果，用户无需先填写图表数据。手动工具仍可在高级工具中使用。
- 中性色、免登录、原有项目数据保留。

## AI 阅读摘记

文献详情的“AI 生成阅读摘记”明确点击后会创建专用对话并真实发送任务，使用当前选择的模型。无摘要时阻止发送，不冒充已读取 PDF。

Agent 读取登记的标题和摘要，生成研究问题、方法、结果、局限与待验证问题，通过原生审批工具保存独立草稿。UI 标记“AI 草稿 · 待核查”，显示来源 ID、摘要范围、时间和来源版本；原文变化提示草稿过期。人工笔记不自动覆盖，用户核查后复制采用。

本轮真实模型成功为 *A new Monte Carlo technique: antithetic variates*（DOI `10.1017/s0305004100031455`）生成并保存了摘要级中文摘记。摘要来自完整科研测试中真实 Crossref 解析，复用本地元数据不是新全文抓取。真实稿件在 `deliverables/v0.8.0/ai-reading-draft.md`。

首次截图步骤被残留审批弹窗挡住；随后不重复调用模型，重启应用验证草稿能显示且持久保存。对应记录：`test-results/live-reading-OINmHS/report.json` 与 `ui-verification.json`。不能将原脚本失败退出码当成完整 UI 测试通过。

## 自动科研底层

22 个本地 MCP 工具，13 个只读、9 个需要逐次审批的网络/写入/执行动作。新增原生文献搜索、DOI导入、实验代码登记、计划/分析/交接文件写入、内联图表、DOCX写稿与阅读摘记保存。所有动作限定当前项目、输入有界、危险操作需批准，不通过禁用安全措施绕过 PowerShell 问题。

分析与审查报告必须和所列成功 run 的实际 JSON 输出哈希一致；机械核对和待人工审阅分开。DOCX 可实际嵌入本地结构化图的栅格兼容版本，PPT仍保留原生图表与可编辑数据。

## 完整科研实测状态

完整八阶段现已在同一项目中通过：模型检索来源、编写并执行正式实验/分析/审计，自动创建图表/PPT并生成修订DOCX。过程包含多次限流恢复和应用修复，不是一次无故障无人值守运行。最终状态与独立核验见 `docs/full-research-validation.md`，原始记录保留于 `test-results/full-research-dZMiVw/`。

**不以局部成功冒充题目到成稿全流程完成。** 此测试是CPU数学仿真方法比较，不是现实应用验证或新算法发现。

- 类型检查通过，176 项自动化测试通过，0 失败、0 跳过。
- 实际桌面回归20项通过，包含文献记录、RAG、实验草稿、高级图表入口、SVG/PPT导出、重启保存与窄窗口布局。

- 完整科研从宽题目运行的所有失败、恢复和阶段产物保留；最终以完整科研验证报告为准，没有把局部测试计作整条流水线成功。

## 当前范围限制

- AI 摘记仅标题/摘要，不含安全PDF全文解析、页码定位或全文问答。
- 图表支持结构化柱状/折线/散点/流程图，暂无原生误差棒和对数轴；不得为适配样式删除不确定性。
- PPTX为对应科研图的可编辑单页素材，不是自动排好整套答辩演示。
- 未接入知网/维普官方数据库，不承诺AI检测或查重通过。
