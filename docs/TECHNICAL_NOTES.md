# 技术说明与数据管理

本文供需要了解实现细节、保存范围或排查问题的读者参考。安装和日常使用从 [安装与配置](DEPLOYMENT.md) 开始即可。

## 数据与草稿

ResearchPilot 使用本地数据库保存项目记录，项目目录保存文稿、实验代码、运行产物和图表文件。

| 内容 | 保存方式 |
| --- | --- |
| 文献元数据、阅读笔记、独立研究笔记 | 本地数据库 |
| PDF 高亮与批注 | 本地数据库，关联文献与 PDF 文件哈希 |
| 文稿与版本快照 | 项目文件与数据库记录 |
| 实验代码、运行结果和图表 | 项目目录及相应记录 |
| 模型 Key | 操作系统安全存储；Windows 使用 DPAPI |
| 聊天输入、未保存代码、写作检查等编辑草稿 | 应用内存，关闭或刷新前请保存 |

研究笔记通过稳定 ID 建立内部链接，并用 revision 检查避免旧内容覆盖新修改。笔记可导出为 Markdown；回收站保留已删除笔记供恢复。

PDF 批注独立于原文件保存。替换附件后，原文件的标注仍与旧哈希对应。阅读器支持文字高亮、页面批注、翻页和缩放；OCR、外部标注同步和写回 PDF 属于其他工作流程。

### 项目备份

`.rpbackup` 保存单项目的文献、文稿及版本、研究笔记、阅读草稿、PDF 批注、图表、实验代码与允许的研究文件。恢复创建新的项目目录和记录 ID，保留原项目。

备份范围不包括模型 Key、SSH 配置、聊天、流水线、搜索索引、隐藏配置和运行日志。搜索索引可以重新建立。文件未加密，适合保存在自己控制的可信位置。

### 目录恢复与升级

已有项目目录丢失或无权访问时，项目记录仍保留，其他项目可以继续工作。找回原目录或修复权限后，在使用准备检查中重试初始化。

旧版账户数据沿用本地工作区兼容路径，其他旧账户目录保持原样。需要迁移资料时，优先使用项目备份，而不是直接覆盖数据库。

## 项目知识检索与全文阅读

自动项目知识检索采用本地 BM25，索引文献标题、摘要和阅读笔记。助手每轮提问检索相关片段，带来源定位加入上下文。匹配的片段会随问题发送给所选模型服务。

PDF 分页阅读是另一条入口：文献详情的“提取全文页”和 Agent 的 `reference_fulltext` 使用相同文字提取引擎，返回页序号、文本偏移、文件哈希和续读位置。它支持按批次阅读长文，尚未自动纳入项目知识索引。

这里的页码是 PDF 页序号。文字提取可能无法完整表达图像、公式和复杂表格；无文字层的页面会单列，适合配合原页面视觉阅读或 OCR。

“AI 生成阅读摘记”按钮仍使用登记的标题和摘要，结果与人工笔记分开保存；需要全文支持的任务请使用全文核对技能与关联 PDF。

## 模型与角色配置

模型列表通过提供方的 API 获取。应用保存上游明确返回的上下文、输出上限与能力声明，未返回的项目显示未知。上下文、输出上限和视觉输入声明用于相应运行时配置；实际服务行为可通过主动调用确认。

三种角色分别引用提供方和模型 ID，Key 继续由提供方管理。技能任务创建对应角色会话；流水线保存本次角色配置，按阶段使用独立会话并交接摘要与项目产物。运行期间修改全局角色设置，不会悄悄改变已启动流程的模型选择。

科研问询设置控制澄清偏好，与操作审批分开：偏好默认值可以减少打断，执行、联网和文件操作仍走各自确认流程。

## 绘图与文稿

### 结构化图形

当前原生格式支持柱状、折线、散点和方法流程图。每图保存 JSON、SVG、PPTX：

- 数据图的 PPTX 包含原生图表与嵌入工作簿，可在 PowerPoint 中编辑数据。
- 方法图由独立形状、文字和箭头组成，移动节点后可手动调整连接。
- 数据图最多 3 个系列、200 个点；流程图最多 40 个节点、80 条边。

误差线、热图等更灵活的表现可使用 Python 绘图流程。Python 路径保留代码与栅格图稿，适合与结构化图稿按需选用。

### 写作与检查

DOCX 支持可视化编辑，LaTeX 支持源码编辑与本地编译。写作质量页提供套话、重复、长句和引文占位符等本地检查，以及与用户提供文本的局部重合对照。

这些结果是编辑线索。知网、维普等外部平台报告可以作为用户提供的修订材料，应用没有接入其检测数据库。

“另存修订稿为 DOCX”生成独立文字文档；需要保留旧稿图片、公式或复杂版式时，使用原文稿编辑流程并检查导出结果。

## 本地工具与执行环境

应用提供三个 stdio MCP 服务，共 24 个工具：文献与证据、文稿与表达、实验与图表。其中 14 个只读，10 个网络、写入或执行动作逐次确认。

自动研究的原生本地实验工具使用已配置 Python，单次运行范围为 30–120 秒。更大计算任务可在实验台结合配置好的本地或 SSH 环境组织。依赖包由选用的研究环境管理。

技能包是方法说明、模板、脚本和检查资源的组合。已有统计脚本支持两组均值差的独立或配对 bootstrap；其他方法技能提供相应分析步骤，实际计算取决于所配置环境和代码。

### 作者指南获取

`journal_guidelines_fetch` 经确认后读取指定 HTTPS 公网链接的 HTML、文本或 PDF，返回 URL、时间、哈希和正文。当前使用受约束直接 HTTPS：固定已验证的公网 IPv4 解析，响应上限 2 MiB，总时限 30 秒。

获取过程不带浏览器登录态，也不自动跟随重定向。遇到跳转时可提供最终指南链接；需要登录或动态页面时，可提供指南正文。随后按页面实际期刊、文章类型和版本整理要求。

## 开发与验证

常用检查与打包命令见 [部署教程](DEPLOYMENT.md)。桌面测试在 `test-results/` 中创建隔离工作区；`test:live`、网关探针和 `live-*.mjs` 是可选的真实模型验证，运行时可能产生服务商费用。

开发环境可通过 `RESEARCHPILOT_USER_DATA` 和 `RESEARCHPILOT_WORKSPACE_ROOT` 指定隔离目录；打包应用使用正式数据位置。

历史验证报告中的本机 `test-results/`、`deliverables/` 路径不随源码发布。报告用于记录当时的过程与结果；当前下载以 [GitHub Releases](https://github.com/lafin-123/ResearchPilot/releases) 为准。
