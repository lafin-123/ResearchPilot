# ResearchPilot 0.5.0 验证记录

日期：2026-10-23（本机时间）。延续用户认可的中性色界面，本轮集中于项目知识、阅读记录、跨页面草稿和中断恢复。

## 本轮实现

- 项目知识库：标题、摘要与笔记分块索引，本地 BM25，支持中文字符/双字词和英文词项。
- 文献活动：加入、导入、详情阅读、PDF 预览、MCP 读取、笔记修改、PDF 关联、删除均可留记录。区分用户阅读与 AI 读取，一分钟内同通道同文献重复读取去重。
- 每次 AI 请求根据本次问题检索当前项目的相关来源并注入有界上下文，附 sourceId、标题、逻辑路径、定位，不依赖上一聊天记录。
- 聊天文本/附件按项目与会话在内存保留，发送同步锁、异步请求世代校验、旧流与当前会话隔离。
- 实验编辑保留项目/实验内存草稿，显式未保存状态、确认还原和保存快照；运行刷新不覆盖代码。
- 写作检查原文/来源/约束/改稿在当前登录会话按项目保留，改稿可另存独立 DOCX，不覆盖原文。
- 正常关闭应用的流水线中断可重试，已完成阶段保留；显式取消仍为终止。
- 修复 Agent 初始化完成、消息尚未执行时短暂误报空闲的问题。

## 明确的范围限制

- **索引仅覆盖文献标题、摘要、笔记；PDF 正文未索引。** 阅读 PDF 的操作有记录，不等于自动读懂或全文入库。
- 使用本地词项 BM25，不是向量数据库，无外部 embedding、OCR、语义向量重排或跨项目自动共享。
- 最多每字段 24,000 字符、每片段 1,000 字符、单次上下文 8,000 字符；候选与结果有界，页面披露截断。
- 新模型请求中检索片段会发送给当前模型提供方；来源被标为不可信资料，不作为指令执行。敏感信息仍需用户审查。
- 草稿保留属于内存会话：刷新、退出登录、关闭应用后清空；文献、阅读记录与知识索引持久化。
- 改稿另存 DOCX 是文字重建，不保留原稿复杂版式或图片、公式对象；不自动覆盖原稿。
- 未重跑八阶段全自动科研流水线、官方查重、全部 PDF 解析或大规模检索基准。
