# ResearchPilot 0.6：免注册本地工作区

## 使用变化

打开应用即进入本地工作区，不再要求邮箱、密码、注册、登录或退出账户。模型 API Key 是模型服务凭据，仍需在“模型与设置”填写，与本地账号无关。

首页参考 Notion 的页面组织习惯，保留既有中性色界面：项目页面入口、实际最近编辑文稿、当前项目最近研究会话。没有宣称实现 Notion 的块编辑器、云同步、团队权限或多人协作。

## 数据兼容

继续使用原 `researchpilot.db`、原工作区与项目中已保存的绝对路径，不搬移、不合并、不重写现有项目。旧版首个账户原本就使用这些路径，因此现有默认工作区内容可以直接继续使用。

旧 `accounts.sqlite`、其附属文件和其他旧账户目录保持原样。免注册版本不读取旧密码、不创建新的账号数据库、不擅自导入非默认旧账户内容。旧版多账户数据不会被删除，但本版不提供旧账户切换。

## 保留的保护

移除的是账户门槛，不是文件与工具保护：

- 可信应用窗口与 IPC 来源检查；
- 工作区初始化、关闭期间的访问限制；
- 运行中调用生命周期与桥接令牌校验；
- MCP 项目范围限制；
- 实验与写入动作的明确审批；
- API Key 的操作系统安全存储。

此软件没有 OS 级文件沙箱或磁盘加密保证，同一系统用户应自行保护本机资料。

## 验证结果

- 类型检查通过；121 项自动化测试通过，无失败或跳过。
- 20 项真实 Electron 桌面检查通过，0 renderer 异常。
- 冷启动直接出现工作台，不显示邮箱或密码表单；注册、登录、退出和改密接口均不存在。
- 关闭并重新启动后，原项目、图表、文献阅读历史仍可访问；新安装不创建 `accounts.sqlite`。
- 兼容性测试使用旧数据库与非默认旧账户目录的哨兵文件，确认原始内容未被修改或合并。
- 实际文稿列表显示新保存的修订稿并提供编辑入口。
- 测试截图与记录：`test-results/desktop-k5fowQ/`。本轮未调用付费模型。
