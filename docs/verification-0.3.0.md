## 覆盖的行为

- 通过真实表单注册、错误密码拒绝、重新登录、修改密码、退出与账户切换。
- 未登录时主进程拒绝项目数据调用，第二账户不能查询第一账户的项目。
- 一键研究在模型未配置时拒绝启动，不留下虚假运行记录。
- 图表工作室通过真实表单创建、生成、下载 PPTX。
- 数据图包含原生图表和嵌入式 XLSX；流程图包含独立形状、文本与箭头，没有整页图片。
- 图表编辑与源数据保存往返一致；演示数据明确标记非证据。
- 缺产物、失败实验、演示图、路径越界不能通过流程检查；失败重试、取消、文稿创建失败和重启恢复均有测试。
- 离线数据审计、两组统计分析、复现哈希检查、引文核验与 PPTX 编辑性检查脚本有测试。
- 小尺寸工作台没有水平溢出。
